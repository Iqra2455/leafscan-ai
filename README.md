# 🌿 Crop Disease Detection AI App

A modern AI-powered web app that helps farmers detect crop diseases by uploading leaf images and getting instant predictions with treatment suggestions.

---

## 🚀 Features

### 🧠 AI Disease Detection
- Upload crop leaf images
- Get disease prediction
- Confidence score
- Severity level
- Treatment recommendations

### 📤 Image Upload
- Drag & drop upload
- Image preview
- Analyze button with loading animation

### 📊 Result Display
- Disease name
- Confidence percentage
- Severity badge (Low / Medium / High)
- Suggested treatments

### 🎨 UI Features
- Clean nature-inspired design (green, white, earthy tones)
- Modern card-based layout
- Glassmorphism effects
- Smooth animations & hover effects
- Dark mode support

---

## 🧱 Tech Stack

- React.js
- Tailwind CSS
- AI Model (CNN / ML backend)
- REST API for predictions

---

## 📱 UI Sections

- Hero Section (title + upload CTA)
- Image Upload Area
- Prediction Result Card
- Features Section
- Footer

---

## 🎯 Goal

Help farmers quickly detect crop diseases and get AI-based treatment suggestions to improve crop health and yield.
